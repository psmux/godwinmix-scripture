The first release of Bible Verses and Lyrics for GodwinMix.

* Bible lookup by reference as people type it, and search by words, in the
  bundled King James Version and World English Bible (both public domain).
* Import of a translation the church is licensed to show: USFM, OSIS XML,
  Zefania XML or a book,chapter,verse,text table. Optional API.Bible with the
  church's own key.
* A song library with verse, chorus and bridge order. Import plain text,
  OpenLyrics and ChordPro.
* Five styles over the programme, with font, size, colour, box, shadow,
  alignment and margin, at 720p and 1080p.
* A panel in the mixer with keyboard stepping, blank and clear, and a stage
  display page for the band.

Install with `gmx plugin add psmux/godwinmix-scripture` or from the mixer's
Plugins page. Needs GodwinMix 0.3.9 or newer and Python 3.10 or newer.

Every archive holds the same files; there is one per platform because the
mixer picks the asset named for its own platform.
